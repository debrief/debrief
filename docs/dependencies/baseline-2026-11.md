## What the scan adds to the plan

The plan was written from the source and build files. The scan found exposure the plan doesn't cover yet:

1. **Native Windows libraries.** `org.mwc.debrief.legacy/src/native/windows/` is a bundled GDAL and MapServer toolchain (45 files), used by GeoPDF export. It sits in a source folder, so it ships inside `debrief_legacy.jar`. Grype identifies only some of it: libpq 12.3 (43 High), libxml2 2.9.8 (1 Critical) and zlib 1.2.3 (3 Critical). The rest, which includes OpenSSL 1.1 (`libcrypto-1_1-x64.dll`, `libssl-1_1-x64.dll`, end of life since 2023), libcurl and GDAL 3.2, **isn't identified**, so the real exposure is higher than the counts show. Pepys's `native/win64/` adds SQLite 3.31.1 (2 Critical, 13 High) and zlib 1.2.8 (3 Critical).
2. **Java libraries not in the plan's list:** h2 1.4.200 in `cmap.geotools` (2 Critical), logback 0.9.14 in `cmap.media` (Critical), gt-jdbc 21.2 (Critical, waits for the GeoTools spec), c3p0 and mchange-commons in Pepys, guava 14 and 27, commons-io 2.1 and 2.6, zip4j 1.3.2.
3. **XStream 1.4.12 doesn't work on Java 21.** The new XY-plot round-trip test showed that `new XStream()` throws `InaccessibleObjectException`: it can't reach `java.util.TreeMap` and the product doesn't open `java.util`. Saving and restoring an XY plot was broken on `develop`. This PR moves the XStream bump (planned for PR 3) forward to 1.4.21, which has no known vulnerabilities, and adds the type allow-list.
4. **Jackson 1.9.4 and postgresql 8.3 have no fixed versions** (Jackson 1: 1 Critical, 1 High). Gate A needs a written exception in `.github/grype.yaml` for each, or their removal in Phase D3.
5. **Five jars aren't identified, so they aren't scanned:** `jmf.jar`, `nanoxml-2.2.1.jar`, `org.json.jar` and the installer's p2 `artifacts.jar`/`content.jar`. Their versions need checking by hand.
6. **A NarrativeWriter test already existed** (`NarrativeWriter.TestMe`), but it wasn't in the test suite, so it never ran. This PR registers it in `AllTests`.

## Proposed additions to the plan

- **PR 3+:** add h2 (to 2.x, but check that GeoTools 21.2 accepts it), logback (or remove `cmap.media`'s logging if unused), the Pepys native SQLite and zlib DLLs (or rely on the sqlite-jdbc bundled natives), c3p0/mchange, zip4j and commons-io.
- **A native-libraries item,** possibly its own spec: replace or remove the bundled GDAL toolchain, or download it at first use. List every DLL and its version, since Syft can't.
- **PR 2:** remove the unused jars listed below, where checks confirm they're unused.
